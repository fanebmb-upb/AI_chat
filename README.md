# Studyflow

A first student-planning app for organizing a study day, tasks, goals, and focus data.

## Run locally

Requires Python 3. No packages are needed.

```powershell
python app/main.py
```

Then open http://127.0.0.1:8000. Press Ctrl+C in the terminal to stop the server.

## Starter features

- Today dashboard with a sample schedule, focus summary, task list, and goal progress.
- Add tasks and mark tasks complete. Task changes are saved in this browser with local storage.
- Schedule, tasks, goals, and insights navigation.
- Responsive layout with a mobile navigation drawer.

The schedule, goals, and study metrics are sample data for this first version. They are not synced between devices yet.
